# Student Performance Analysis

## Project Overview
This project analyzes factors that affect student final grades using NumPy.

The goal is to identify which student-related factors have the strongest impact on academic performance.

---

## Dataset
Student performance dataset containing academic, social, and personal factors.

Columns analyzed:

- Study Time
- Failures
- Gender
- Absences
- Going Out
- Higher Education Aspiration
- Internet Access
- School Support

---

## Technologies Used

- Python
- NumPy
- Matplotlib

---

## Key Findings

### 1. Failures had the strongest negative impact
Students with more past failures scored significantly lower.

---

### 2. Higher education aspiration showed strong positive effect
Students planning higher education scored higher on average.

---

### 3. Internet access had moderate positive impact
Students with internet access performed slightly better.

---

### 4. Other factors showed weaker effects
Study time, goout, absences, and school support showed smaller relationships.
